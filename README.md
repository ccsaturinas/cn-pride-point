## Deployment

Linux and macOS

```bash
./gradlew -Pvaadin.productionMode=true bootBuildImage
```

Command on Windows

```bash
./gradlew "-Pvaadin.productionMode=true" bootWar
```

The WAR file is created in the /build/libs folder.
